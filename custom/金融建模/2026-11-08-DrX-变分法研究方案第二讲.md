# DrX-变分法研究方案 · 第二讲：用 Euler-Lagrange 方程攻打例 1.6——bang-bang 解的由来与 Merton 问题对照

**DrX Quantitative Research** · 2026年11月8日

本篇是"变分法研究方案"的第二讲。第一讲《DrX-从 Hamilton-Jacobi 方程到 Black-Scholes 方程》在文末留了二选一的预告：(A) Feynman-Kac 公式的严格化，用 Sobolev 空间与半群理论的语言给出证明框架；(B) 回到方案第一阶段，用 Euler-Lagrange 方程求解张恭庆《变分学讲义》[1] 第一讲的例 1.6（商品的再投资），并对照 Merton 问题。本讲选定 (B)：理由是顺序上的——(A) 需要的 Sobolev 空间与线性边值问题恰好是逐讲研读第九至十三讲的内容，等研读推进到那里再严格化不迟；而例 1.6 是整个方案第一阶段的"过关题"（见[《DrX-变分法金融数学学习路径》](2026-11-03-DrX-变分法学习路径与策略实现规划.html)），它同时是 Merton 问题的确定性骨架，越早解剖越好。

例 1.6 在逐讲研读[第一讲](2026-11-07-DrX-变分学讲义第一讲.html)里已经用 Pontryagin 最大值原理预解过，结论是 bang-bang 解与开关时刻 $t^{\ast} = T - 1/\alpha$。但研读第一讲同时留了一句话：要检验"例 1.6 的解为什么不能由 Euler-Lagrange 方程直接给出"。本讲就把这句话兑现，并把问题问到底，共三问。第一问：把状态方程消去之后，例 1.6 成为一个关于产出率 $q$ 的标准变分问题，Euler-Lagrange 方程（下称 E-L 方程，推导见逐讲研读[第二讲](2026-11-07-DrX-变分学讲义第二讲.html)）对它究竟说了什么？第二问：不用最大值原理、只用第一阶段的工具（变分、比较与初等分析），怎样严格地把 bang-bang 解证出来？第三问：把同一套 E-L 机器搬到 Merton 问题上，为什么这次它完全够用、给出的还是经济学里著名的 Ramsey 规则？三问的答案最后收成一条分界线：被积函数对控制（或导数）是线性还是严格凹，决定了最优解是开关型的还是光滑内点型的，也决定了 E-L 方程是退化还是胜任。

## 一、例 1.6 的复述与改写：消去状态方程

先把问题按原书一字不差地摆出来 [1，§1.4，例 1.6]。生产一种商品，单位时间产出率为 $q = q(t)$，生产增长的速度 $\dot{q}$ 与产品的再投资百分数 $u(t)$ 成正比，即

$$
\dot{q} = \alpha u q
$$

其中 $\alpha > 0$ 是常数。在时间区间 $\lbrack 0, T \rbrack$ 内投放市场的总商品量是

$$
J(u, q) = \int\_{0}^{T} (1 - u(t)) q(t) \, dt
$$

已知 $q(0) = q\_{0} > 0$，怎样选择再投资百分数 $u(t)$ 使总商品量达到极大值？可行集是

$$
M = \lbrace (u, q) \in C\lbrack 0, T \rbrack \times C^{1}\lbrack 0, T \rbrack \mid 0 \le u(t) \le 1, \ \dot{q} = \alpha u q, \ q(0) = q\_{0} \rbrace
$$

$u$ 是控制变量，$q$ 是状态变量，$J$ 是目标泛函 [1，§1.4，例 1.6]。

**改写：把 $u$ 用 $q$ 表示，问题变回标准形式。** 状态方程可以反解出控制：$u = \dot{q} / (\alpha q)$（注意 $q(t) > 0$ 恒成立，因为 $q(t) = q\_{0} \exp(\alpha \int\_{0}^{t} u(s) ds) \ge q\_{0}$）。代回目标泛函，$u$ 与状态方程同时消失：

$$
J\lbrack q \rbrack = \int\_{0}^{T} \left( q - \frac{\dot{q}}{\alpha} \right) dt, \qquad L(t, q, \dot{q}) = q - \frac{\dot{q}}{\alpha}
$$

约束 $0 \le u \le 1$ 翻译成对导数的逐点约束 $0 \le \dot{q} \le \alpha q$；左端 $q(0) = q\_{0}$ 固定，右端 $q(T)$ 自由（终端产能没有任何残值，愿意剩多少剩多少）。这已经是逐讲研读的标准模板：一阶积分泛函、一个固定端点、一个自由端点，外加一条导数不等式约束。下面就对 $L$ 正面使用 E-L 方程。

## 二、E-L 方程的正面进攻：它在这里退化

对 $L(t, q, \dot{q}) = q - \dot{q}/\alpha$ 计算两个偏导数：

$$
L\_{q} = 1, \qquad L\_{\dot{q}} = - \frac{1}{\alpha} \quad (\text{常数})
$$

E-L 方程 $L\_{q} - \frac{d}{dt} L\_{\dot{q}} = 0$ 变成

$$
1 - 0 = 0
$$

这是一个假命题。也就是说：**这个泛函没有任何一条驻点曲线**——不存在使一阶变分在任意方向上为零的容许 $q$。把一阶变分直接算出来看得更清楚。取容许变分方向 $\eta$（$\eta(0) = 0$，且 $q + \varepsilon \eta$ 在 $\varepsilon$ 小时仍满足导数约束的相应一侧），则

$$
\delta J(q; \eta) = \int\_{0}^{T} \eta \, dt - \frac{\eta(T)}{\alpha}
$$

右端是 $\eta$ 的线性泛函，系数并不恒为零：只要取 $\eta \ge 0$ 且不恒为零、$\eta(T)$ 不太大，$\delta J > 0$，即沿这个方向 $J$ 严格增大。所以任何"内部"的容许曲线都可以被改进，极大值只能在容许集的边界上取得。E-L 方程不是算错了，它是在用"无解"报告一个事实：**最优点不在驻点处，驻点理论在此失效，要改用边界与不等式的语言。**

失效的根源可以精确定位，是三条叠加：

- **$L$ 对 $\dot{q}$ 是线性的。** $L\_{\dot{q}\dot{q}} = 0$，Legendre 条件退化为等式。这是逐讲研读第二讲列举的"可解情形"里最奇异的一种：被积函数对导数一次齐次或线性时，E-L 方程要么恒成立、要么无解，极值曲线的信息全部跑到约束与角点上去了。
- **变分本身是受约束的。** 标准 E-L 推导要求变分方向 $\eta$ 可正可负、双向任意；这里 $\dot{q}$ 被夹在 $0$ 与 $\alpha q$ 之间，站在边界上的曲线只允许单侧变分，一阶条件自然从"等式"变成"不等式"——这正是最大值原理中 Hamilton 函数对控制取极大这一不等式条件的来源。
- **角点被自动放行。** Erdmann 角点条件要求 $L\_{\dot{q}}$ 跨越角点连续；这里 $L\_{\dot{q}} = -1/\alpha$ 是常数，条件平凡成立，于是 $\dot{q}$ 可以自由跳跃。后面会看到，bang-bang 解的开关点正是一个 $\dot{q}$ 从 $\alpha q$ 跳到 $0$ 的角点（$q$ 本身连续、导数跳跃）：E-L 体系不但不禁止它，反而为它留好了位置。附带一提，逐讲研读第四讲的 Weierstrass 过剩函数在这里恒等于零（$L$ 对导数线性时，过剩函数按定义逐项抵消），即强极值的充分条件也给不出任何信息——光滑理论的一阶、二阶、场论三层工具在此集体沉默，原因统一：目标与动力学对控制是双线性的。

## 三、严格求解：一个恒等式、一个分点、一条不等式

不用任何光滑驻点理论，只用微积分基本定理与两条放缩，就能把最优解完整证出来。先对任意容许 $q$ 做化简。由 $\dot{q} = \alpha u q$ 得 $u q = \dot{q}/\alpha$，积分并用微积分基本定理：

$$
\int\_{0}^{T} u q \, dt = \frac{q(T) - q\_{0}}{\alpha}
$$

于是总投放量有一个干净的等价形式：

$$
J = \int\_{0}^{T} q \, dt - \frac{q(T) - q\_{0}}{\alpha}
$$

读法是会计式的：总投放 = 总产出 − 总再投资，而总再投资只由始末产能之差决定，与路径无关。路径真正能影响的只有两件事：总产出 $\int\_{0}^{T} q \, dt$（产能爬得越高、越早，越大）与终端产能 $q(T)$（它按 $1/\alpha$ 的价格从投放里扣减）。最优问题就是在这两者之间权衡。

**分点不等式。** 任取一个分点 $s \in \lbrack 0, T \rbrack$，把总产出拆成两段分别放缩。前段用"增长至多以全速 $\alpha$"：$q(t) \le q\_{0} e^{\alpha t}$（因为 $\dot{q} \le \alpha q$），得

$$
\int\_{0}^{s} q \, dt \le \int\_{0}^{s} q\_{0} e^{\alpha t} dt = \frac{q\_{0} (e^{\alpha s} - 1)}{\alpha}
$$

后段用"产能不减"：$u \ge 0$ 蕴含 $\dot{q} \ge 0$，故 $q(t) \le q(T)$ 对 $t \le T$ 成立，得

$$
\int\_{s}^{T} q \, dt \le (T - s) q(T)
$$

两式代回化简式，任意容许 $q$ 都满足

$$
J \le \frac{q\_{0} e^{\alpha s}}{\alpha} + q(T) \left( T - s - \frac{1}{\alpha} \right)
$$

注意右端第二项带着不可控的 $q(T)$，但它的系数可以由我们挑选 $s$ 来消掉。取

$$
s^{\ast} = T - \frac{1}{\alpha} \qquad (\text{先设 } T > 1/\alpha)
$$

系数恰为零，$q(T)$ 整个消失，得到与路径无关的上界 $J \le q\_{0} e^{\alpha s^{\ast}} / \alpha$。而这个上界可以达到：取 $u^{\ast} = 1$ 于 $\lbrack 0, s^{\ast})$、$u^{\ast} = 0$ 于 $(s^{\ast}, T \rbrack$，即 $q^{\ast}$ 先按 $q\_{0} e^{\alpha t}$ 增长、后保持常数 $q\_{0} e^{\alpha s^{\ast}}$，直接计算得

$$
J(u^{\ast}) = (T - s^{\ast}) q\_{0} e^{\alpha s^{\ast}} = \frac{q\_{0} e^{\alpha s^{\ast}}}{\alpha}
$$

与上界相等。再看等号成立的条件：前段放缩取等要求 $\dot{q} = \alpha q$ 几乎处处成立（即 $u = 1$），后段取等要求 $q$ 在 $\lbrack s^{\ast}, T \rbrack$ 上恒等于 $q(T)$（即 $u = 0$），所以最优解在差一个零测集的意义下唯一，就是上面的 bang-bang 解。

若 $T \le 1/\alpha$，在分点不等式里取 $s = 0$：右端变为 $q\_{0}/\alpha + q(T)(T - 1/\alpha)$；此时系数 $T - 1/\alpha \le 0$ 而 $q(T) \ge q\_{0}$，故 $J \le q\_{0}/\alpha + q\_{0}(T - 1/\alpha) = q\_{0} T$，等号在 $q(T) = q\_{0}$ 即 $u \equiv 0$ 时成立——时限太短，再投资一分不投，全部投放。这与研读第一讲用最大值原理得到的结果逐字一致。

**捷径与对照。** 如果先用直觉猜到"最优必是先满投、后停投"的单参数族 $u = \mathbf{1}\_{\lbrack 0, s \rbrack}$，则 $J(s) = (T - s) q\_{0} e^{\alpha s}$ 只是一元函数，求导得

$$
J^{\prime}(s) = q\_{0} e^{\alpha s} \lbrack \alpha (T - s) - 1 \rbrack
$$

符号由 $\alpha (T - s) - 1$ 决定：$s < s^{\ast}$ 时为正、$s > s^{\ast}$ 时为负，极大在 $s^{\ast} = T - 1/\alpha$。这条捷径给出候选，分点不等式给出证明，两者缺一不可——只有捷径是猜测，只有一阶条件则连候选都定位不到（第二节）。还有一层值得点破：分点 $s$ 的挑法"令 $q(T)$ 的系数为零"，与最大值原理里协态变量 $\lambda(t) = T - t$ 在末段的形状是同一件事：$\alpha \lambda(t) = 1$ 的解正是 $t = T - 1/\alpha$。确定性控制里，乘子、对偶变量与这里的"消元分点"三位一体，第十四讲的对偶作用原理会把这层关系系统化。

**经济读法。** $1/\alpha$ 是再投资的"回本期"：在时刻 $t$ 投入生产的每一单位产能增量，需要靠剩余时间内多产出的量来偿还；剩余时间恰好等于 $1/\alpha$ 时，继续投资的边际回报与直接投放持平，此前投资划算、此后不划算。开关时刻只依赖 $T$ 与 $\alpha$，与初始规模 $q\_{0}$ 无关（问题对 $q$ 是齐次的，规模只按比例放大 $J^{\ast}$）。

## 四、数值核验

取研读第一讲习题里的数据 $\alpha = 0.50$、$T = 3.00$、$q\_{0} = 100.00$，则 $1/\alpha = 2.00$，开关时刻 $s^{\ast} = 1.00$。把单参数族 $J(s) = (3.00 - s) \times 100.00 \times e^{0.50 s}$ 在几个分点上算出来，验证极大确实落在 $s^{\ast}$：

| 开关时刻 $s$ | $q(T)$ | 总投放量 $J(s)$ |
| :--- | :--- | :--- |
| 0.00（从不投资） | 100.00 | 300.00 |
| 0.50 | 128.40 | 321.01 |
| 1.00（$s^{\ast}$） | 164.87 | 329.74 |
| 1.50 | 211.70 | 317.55 |
| 2.00 | 271.83 | 271.83 |
| 2.50 | 349.03 | 174.52 |
| 3.00（全程投资） | 448.17 | 0.00 |

表里两件事与理论严丝合缝：其一，$J(s)$ 先升后降、峰值在 $s^{\ast} = 1.00$，最优总投放 329.74 比从不投资的 300.00 多 29.74（多 9.91%）；其二，$q(T)$ 随 $s$ 单调上升、$J$ 却不是——把产能推到最高（全程投资、$q(T) = 448.17$）反而一无所获，因为投放发生在时间内、产能只在终点结算。这个对照是理解目标泛函结构的最好方式：$J$ 奖励的是"产能 × 剩余投放时间"的乘积，不是产能本身。

## 五、对照 Merton 问题：同一台机器，为什么这次够用

Merton 问题是例 1.6 的金融版：把"产能"换成"财富"、"再投资比例"换成"消费与投资决策"，目标换成效用的贴现积分。为了看清 E-L 方程的适用边界，先剥掉噪声，只保留确定性骨架（这正是 Ramsey 新古典增长模型的核心方程）。

### 5.1 确定性 Merton：E-L 给出 Ramsey 规则

设财富 $W(t)$ 按 $\dot{W} = r W - c$ 演化（$r$ 为无风险利率，$c(t) \ge 0$ 为消费率；收入项略去不影响结构），目标是

$$
\max \int\_{0}^{T} e^{- \rho t} U(c) \, dt, \qquad W(0) = W\_{0}, \quad W(T) = 0
$$

其中 $\rho > 0$ 是主观贴现率，$U$ 严格凹（$U^{\prime} > 0$，$U^{\prime\prime} < 0$）；终端条件 $W(T) = 0$ 表示到期耗尽（换成给定的遗产 $W(T) = \bar{W}$ 结构不变）。与例 1.6 同样手法，由状态方程解出控制 $c = r W - \dot{W}$ 代回，问题化为关于 $W$ 的标准变分问题，被积函数

$$
L(t, W, \dot{W}) = e^{- \rho t} U(r W - \dot{W})
$$

这次 E-L 方程有实实在在的内容。算两个偏导数（记 $c = r W - \dot{W}$）：

$$
L\_{W} = e^{- \rho t} r U^{\prime}(c), \qquad L\_{\dot{W}} = - e^{- \rho t} U^{\prime}(c)
$$

E-L 方程 $L\_{W} - \frac{d}{dt} L\_{\dot{W}} = 0$ 展开为 $r U^{\prime}(c) - \rho U^{\prime}(c) + U^{\prime\prime}(c) \dot{c} = 0$，即消费路径必须满足

$$
\dot{c} = (r - \rho) \frac{U^{\prime}(c)}{- U^{\prime\prime}(c)}
$$

取教科书标准的 CRRA 效用 $U(c) = c^{1 - \gamma} / (1 - \gamma)$（$\gamma > 0$ 为相对风险厌恶系数），$U^{\prime}(c) = c^{- \gamma}$，$- U^{\prime\prime}(c) = \gamma c^{- \gamma - 1}$，上式立刻化为著名的 **Ramsey 规则**：

$$
\frac{\dot{c}}{c} = \frac{r - \rho}{\gamma}
$$

利率高于贴现率时消费沿最优路径匀速增长、反之匀速递减，增长率被风险厌恶 $\gamma$ 缩放：越厌恶风险，消费路径越平。解是光滑的、内点的，E-L 方程一击命中——与例 1.6 的"1 = 0"形成鲜明对照。对照的要点不在技巧而在结构：**效用 $U$ 对消费严格凹，使被积函数对 $\dot{W}$ 严格凹（$L\_{\dot{W}\dot{W}} = e^{- \rho t} U^{\prime\prime}(c) < 0$），Legendre 条件以严格不等式成立，驻点真实存在且是极大点。** 例 1.6 里被积函数对导数线性、曲率为零，驻点不存在，解被挤到边界上。E-L 方程够不够用，不取决于问题来自经济学还是工程，只取决于被积函数对"斜率变量"的曲率符号。

### 5.2 随机 Merton：HJB 接棒

把噪声加回来，就是 Øksendal 的问题 6 [2，§1.5，式 (1.5.1)–(1.5.3)] 与第 11 章的随机控制框架 [2，Ch. 11]：财富满足受控随机微分方程（以 $u\_{t} \in \lbrack 0, 1 \rbrack$ 记投入风险资产的财富比例）

$$
d X\_{t} = \lbrack b u\_{t} + r (1 - u\_{t}) \rbrack X\_{t} \, dt + \sigma u\_{t} X\_{t} \, d B\_{t}
$$

目标是终端财富的期望效用 $\max \mathbb{E} \lbrack U(X\_{T}) \rbrack$。这次连"消去状态方程化为标准变分问题"的路都走不通：状态是随机过程、控制必须适应信息流（不能偷看未来），驻点条件要换成值函数的 Hamilton-Jacobi-Bellman 方程。以 CRRA 效用求解（猜测值函数形式并用验证定理核对，见 [2，Ch. 11]），最优策略是**常比例**的：

$$
u^{\ast} = \frac{b - r}{\sigma^{2} \gamma}
$$

（$b$ 为风险资产的期望收益率，$\gamma$ 为相对风险厌恶；要求参数使 $u^{\ast} \in \lbrack 0, 1 \rbrack$，否则解同样被约束挤到边界、回到 bang-bang 式的角点解。）三代问题并排，分界线一目了然：

| | 例 1.6 再投资 | 确定性 Merton（Ramsey） | 随机 Merton |
| :--- | :--- | :--- | :--- |
| 状态方程 | $\dot{q} = \alpha u q$ | $\dot{W} = r W - c$ | 受控 SDE（含 $d B\_{t}$） |
| 目标对控制的曲率 | 线性（曲率 0） | 严格凹（$U^{\prime\prime} < 0$） | 严格凹 + 噪声 |
| 最优解的结构 | bang-bang 开关解 | 光滑内点路径 | 常比例反馈策略 |
| 决定解的公式 | 开关时刻 $T - 1/\alpha$ | 增长率 $(r - \rho)/\gamma$ | 比例 $(b - r)/(\sigma^{2} \gamma)$ |
| 胜任的一阶工具 | 最大值原理（E-L 退化） | E-L 方程（或 H-J 方程） | HJB 方程 + 验证定理 |

还有一个呼应第一讲的观察：随机 Merton 的 $u^{\ast}$ 是常数比例，与例 1.6 的开关时刻一样不依赖状态的规模（两个问题对状态都是乘性的），差别只在噪声把"何时切换"的问题换成了"按什么比例暴露"的问题。而第一讲的 Black-Scholes 方程，正是这类 HJB 方程在"控制被对冲消去"后的线性退化情形——三讲至此在同一张图上接通。

## 六、小结、习题与下一讲预告

**小结。** 本讲把第一阶段的过关题做完了，四句话收束。第一，把控制用状态消去后，例 1.6 成为 $L = q - \dot{q}/\alpha$ 的标准变分问题，但 E-L 方程退化为假命题 $1 = 0$：泛函没有驻点，极大值在容许集边界上，原因是 $L$ 对导数线性、变分受单侧约束、角点条件自动放行。第二，不用最大值原理，只用恒等式 $J = \int\_{0}^{T} q \, dt - (q(T) - q\_{0})/\alpha$ 与分点放缩，挑分点 $s^{\ast} = T - 1/\alpha$ 消去终端项，即严格证出 bang-bang 最优解与唯一性；$T \le 1/\alpha$ 时最优是全程不投资。第三，同一台 E-L 机器搬到确定性 Merton 问题上完全胜任，给出 Ramsey 规则 $\dot{c}/c = (r - \rho)/\gamma$；胜负手是被积函数对斜率变量的曲率。第四，随机 Merton 由 HJB 方程给出常比例策略 $u^{\ast} = (b - r)/(\sigma^{2} \gamma)$，约束一旦咬住又会退回角点解——线性与凹性、内点与边界，是贯穿三代问题的同一条分界线。

**习题**（附答案）。

1. 取 $\alpha = 1.00$、$T = 2.00$、$q\_{0} = 50.00$，求例 1.6 的开关时刻、最优总投放量，并与从不投资比较。答案：$1/\alpha = 1.00$，$s^{\ast} = 1.00$；$J^{\ast} = (2.00 - 1.00) \times 50.00 \times e^{1.00} = 135.91$；从不投资为 $50.00 \times 2.00 = 100.00$，最优多 35.91（即多 35.91%）。
2. 把例 1.6 的控制约束改紧为 $0 \le u \le \bar{u}$（$\bar{u} < 1$，如再投资比例有上限），求最优解。答案：增长上限变为 $\alpha \bar{u}$，第三节证明中增长放缩改用 $\dot{q} \le \alpha \bar{u} q$ 即可；最优仍为 bang-bang：$u^{\ast} = \bar{u}$ 于 $\lbrack 0, s^{\ast})$、$0$ 于其后，开关时刻 $s^{\ast} = T - 1/(\alpha \bar{u})$（当 $T > 1/(\alpha \bar{u})$ 时）；上限越紧，回本期 $1/(\alpha \bar{u})$ 越长、停投越早。
3. Ramsey 规则的数值：$r = 5.00\%$、$\rho = 2.00\%$、$\gamma = 2.00$，问最优消费的增长率；若 $r = 1.00\%$ 又如何？答案：$\dot{c}/c = (5.00\% - 2.00\%)/2.00 = 1.50\%$，消费逐年递增；$r < \rho$ 时为 $(1.00\% - 2.00\%)/2.00 = -0.50\%$，消费逐年递减——利率低于耐心程度时，最优是年轻时多消费。

**下一讲预告。** 研究方案的下一篇回到程函：用逐讲研读第五讲的 Hamilton-Jacobi 理论，把例 1.6 的值函数 $V(t, q)$ 显式写出并验证它满足 H-J 方程——在剩余时间 $\tau = T - t$ 大于回本期 $1/\alpha$ 时 $V = q e^{\alpha (\tau - 1/\alpha)} / \alpha$、小于时 $V = q \tau$，两段在 $\tau = 1/\alpha$ 处光滑相接（一阶导数连续、二阶导数跳跃），是观察"值函数的可微性与最优反馈"关系的最小样本。原预告中的 (A) Feynman-Kac 严格化继续顺延，与逐讲研读的进度对表：等第九至十三讲把 Sobolev 空间与线性边值问题读完，再用那套语言给出证明框架。
